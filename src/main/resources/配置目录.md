# LD-Attribute 配置目录

> 所有配置文件位于 plugins/LD-Attribute/
> 修改后运行 /ldc reload <key> 热重载

---

## 📇 卡片类

| 文件 | 功能 | 热重载 |
|---|---|---|
| item.yml | 卡片定义：ID / 材质 / 属性 / Lore / 元素 / 绑定 | /ldc reload item |
| cardlevel.yml | 卡片升级：最大等级 / 每级属性成长 | /ldc reload cardlevel |
| star.yml | 卡片升星：星级上限 / 每星加成 / 消耗 | /ldc reload star |
| decompose.yml | 卡片分解：获得的点券 / 材料 | /ldc reload decompose |
| suit.yml | 套装系统：套装组合 / 生效条件 / 加成 | /ldc reload suit |
| combo.yml | 卡片组合技能：多卡组合触发战斗效果 | /ldc reload combo |
| resonance.yml | 卡片共鸣：集齐特定卡片组获得加成 | /ldc reload synergy |
| bond.yml | 卡片羁绊：角色组合触发加成 | /ldc reload synergy |
| collection.yml | 卡片图鉴：收集奖励 / 完成度 | /ldc reload collection |
| recipe.yml | 合成配方：材料 + 卡片 → 新卡片 | /ldc reload recipe |

## 🎯 自訂義值類

| 文件 | 功能 | 熱重載 |
|---|---|---|
| value.yml | 自訂義值：Id / 顯示名 / 預設值 / 上限 / 自動恢復 | /ldvalue reload |

**自動恢復（AutoRegen）**：
```yaml
體力值:
  Name: "&a體力"
  Default: 100
  Max: 100
  AutoRegen:
    Amount: 5        # 每次恢復量
    Interval: 60     # 間隔秒數
    Max: 100         # 恢復到多少停止
```

**結構**：
```yaml
Sources:
  - Name: "SX-Attribute"
    Enabled: true
    Provider: "com.longdrange.ldattribute.core.compat.SXAttributeCompat"
    Method: "getSXAttributes"
```
